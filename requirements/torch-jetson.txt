# Jetson Orin (JetPack 6.x / L4T r36.x).

# Intentionally empty. torch and torchvision ship preinstalled in the
# nvcr.io/nvidia/l4t-pytorch base image, built against that JetPack's CUDA and
# cuDNN. Installing torch from PyPI here would overwrite a working build with an
# incompatible one.
#
# The matching numpy<2 constraint (this base image's torch 2.2 is built
# against NumPy 1.x's C API) is NOT here despite this being the per-target
# seam: this file is installed via its own `pip install -r` invocation before
# requirements/base.txt's, and base.txt's explicit numpy==2.2.6 pin would
# just win in the later invocation. See the platform_machine-marker split in
# requirements/base.txt instead, which is the form that actually survives
# both invocations.
